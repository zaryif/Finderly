# 🌟 Finderly App Launcher Icon

The app launcher icon is designed following official Apple Human Interface Guidelines (macOS Big Sur / Sonoma squircle container with drop shadow, subtle inner border, and centered hero folder with Finderly color tags).

### 📐 Specifications

| Property | Value |
|----------|-------|
| **Master Resolution** | `1024 × 1024` (Retina 32-bit RGBA) |
| **Container Shape** | Continuous-curve macOS Squircle (`radius = 185px`) |
| **Background** | Frosted Arctic White gradient (`#FFFFFF` → `#EFEFF2`) |
| **Hero Element** | Exact macOS Big Sur Blue Folder (`folder_blue.png`) |
| **Detail Badges** | Three multi-color tag dots (Blue, Purple, Pink) |
| **Shadow Profile** | Diffuse ambient occlusion drop shadow |

---

### 📁 Output Paths

- **Master File**: `assets/icons/app_icon.png`
- **Android Launcher**: `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`
